# Changelog

## 0.2.0 — functional preview

- Added 3,983 MIT-licensed ATT-derived quest-start records with pinned provenance.
- Added read-only game quest POIs for active objectives and turn-ins, plus missing-coordinate diagnostics.
- Added world-map and minimap overlays, ancestor-map projection, clustering and pin tooltips.
- Added independent map filters, pin sizing, Korean/English UI and saved settings.
- Added D-pad/left-stick settings navigation, confirm/cancel swapping and a paged quest-pin list.
- Added opt-in key binding, native-cursor Q buttons, and `/qmg` settings/status/log commands.
- Added combat/dialogue settings closure and bounded addon-block diagnostics.
- Added deterministic packaging and mocked Lua 5.1 runtime regression tests.

Client integration testing is pending. This is not a claim of verified, taint-free compatibility.
